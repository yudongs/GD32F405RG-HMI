# LCD 测试程序 - 行为规范

## 运行流程

```
上电
  │
  ▼
初始化 LCD
  │
  ▼
┌─────────────────────────────┐
│      测试循环 (永不退出)      │
│                             │
│  ① 纯色填充 → ② 像素点阵     │
│         │         │        │
│  ⑤ UI组件 ← ④ 文字显示       │
│         │         │        │
│         └────③────┘        │
│             │              │
│         ⑥ 数值显示 ─────────┘
│             │
└─────────────┘
```

## 每项测试行为

| 测试 | 持续时间 | 切换方式 |
|------|---------|---------|
| 纯色填充 | 5×1s | 自动 |
| 像素点阵 | 1.5s | 自动 |
| 线条绘制 | 1.5s | 自动 |
| 文字显示 | 1.5s | 自动 |
| UI 组件 | 2s | 自动 |
| 数值显示 | 1.5s | 自动 |

## 验收标准

- [ ] 上电后屏幕立即开始显示测试图案
- [ ] 纯色测试依次显示红绿蓝白黑
- [ ] 点阵测试显示网格图案
- [ ] 斜线测试显示交叉斜线
- [ ] 文字测试显示 ASCII 样本
- [ ] UI 组件测试显示各 Box 图案
- [ ] 数值测试显示数字和十六进制
- [ ] 测试循环永不停止
