# LCD 屏幕诊断测试程序 - 需求

## 基本信息

| 字段 | 值 |
|------|-----|
| 功能名称 | LCD 屏幕诊断测试程序 |
| 目标 | GD32F405RG + ST7586 LCD (240x160) |
| 用途 | 诊断调试 |
| 模块位置 | `APP/lcd_test.c` + `APP/lcd_test.h` |

## 功能需求

### REQ-001 纯色填充测试
- 依次显示：红、绿、蓝、白、黑全屏
- 每色持续约 1 秒

### REQ-002 像素点阵测试
- 显示网格点阵图案
- 验证像素显示功能

### REQ-003 线条绘制测试
- 使用 DrawLine/DrawLine2 绘制斜线
- 验证划线函数正常

### REQ-004 文字显示测试
- 显示 ASCII 字符样本
- 验证 PrintASCII/PrintASCII1216 正常

### REQ-005 UI 组件测试
- 依次调用：Box、Box2、DynamicBox 等
- 验证 UI 组件函数正常

### REQ-006 数值显示测试
- 显示十进制、十六进制数值样本
- 验证 DisplayDecNum 等函数正常

## 非功能性需求

| 项目 | 要求 |
|------|------|
| 性能 | 每项测试 1-2 秒后自动切换 |
| 兼容性 | ST7586 驱动，240x160 分辨率 |
| 循环 | 持续循环，不退出 |

## 不在范围内

- 按钮交互
- 测试报告输出
- 工厂校准
